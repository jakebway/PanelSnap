# PanelSnap: how the app fits together

A SwiftUI iPhone/iPad comic reader (iOS 17+) that snaps the view from panel to panel. Project is generated by XcodeGen
from `project.yml` (`project.lite.yml` is the same without the RAR/7z packages). No Xcode project is committed.

## Where to look
| Area | Files |
| --- | --- |
| App entry, settings | `App/PanelSnapApp.swift`, `Services/AppSettings.swift` |
| Library (shelves, covers, progress) | `Services/LibraryStore.swift`, `Views/LibraryView.swift`, `Models/ComicModels.swift` |
| Opening comics | `Services/ComicSource.swift` (protocol + image decoding), `Zip/Rar/SevenZip/PDFComicSource.swift` |
| Panel detection | `Services/PanelDetector.swift` → `MLPanelDetector.swift` (Core ML YOLO) + `OrderModel.swift` (reading order); results cached by `PanelCache.swift` |
| **Reader** | `Views/ReaderView.swift`, `Views/ZoomLayer.swift`, `Views/PanelCanvas.swift`, `Services/ReaderModel.swift` |
| Companion (who's who) | `Services/Companion/*`, `Views/CompanionView.swift` |
| Browser / Discover / downloads | `Views/BrowserView.swift`, `Services/BrowserModel.swift`, `BrowserShield.swift`, `Views/DiscoverView.swift`, `Services/DiscoverModel.swift`, `SegmentedDownloader.swift` |

## The reader
- `ReaderModel` (main actor) owns the current page image, its panel rectangles (0...1 page coordinates) and `panelIndex`
  (`-1` = whole page). It loads pages off the main thread (decoded once, longest side 2600px), keeps the current page
  and its two neighbours in memory, and prefetches neighbours (de-duplicated, scanning for panels only when snapping is on).
- `PanelCanvas` draws the page and "flies" a camera (scale + offset, spring animation) to the focused panel.
  `PanelCanvas.camera` / `PanelCanvas.panel(at:)` are the pure geometry (also used for tap hit-testing).
- `ZoomState` (in `ZoomLayer.swift`) holds the manual zoom/offset on top of the camera. It is a separate observable so
  zooming redraws only the page. Always change it with `set(zoom:offset:)` (one redraw).

## Reader gestures (who handles what)
| Gesture | Handler |
| --- | --- |
| Tap edges / middle, double-tap zoom | SwiftUI `SpatialTapGesture` in `ReaderView.handleTap` (edges are instant; the middle waits 300 ms for a possible second tap) |
| Swipe left/right (page), up (Companion), down (menu) | SwiftUI `DragGesture` in `ReaderView` → `handleDrag` |
| Pinch (zoom around the fingers; also hands a focused panel over to free zoom) | UIKit `UIPinchGestureRecognizer` on the window, `ZoomGestures.Coordinator.pinched` |
| One-finger pan when zoomed, or nudging a snapped panel | UIKit `UIPanGestureRecognizer` on the window, `Coordinator.panned` / `nudge` |
| Momentum + rubber-band after a drag | `CADisplayLink` in the coordinator (`startGlide` / `glideStep`); moves the real offset so a touch can catch it |
| Drag past the page edge while zoomed → next/previous page | `Coordinator.panned(.ended)` → `onEdgeSwipe` |

The window-level recognisers run alongside SwiftUI's; `ZoomState.lastPinch` keeps the SwiftUI swipe from also firing after
a pinch or nudge. Merging swipe handling into the UIKit pan is the planned next cleanup.

## CI (what Claude without a terminal can read)
- `Build IPA` (`build.yml`): unsigned release IPA + GitHub Release.
- `Check` (`check.yml`): compiles every branch for the iOS Simulator and pushes a report and plain-text source bundles to the
  **`ci-report`** branch: `<branch-name>/status.md` (result, errors, warnings), `build-*.log`, `source/reader.txt`, `source/all.txt`.

import SwiftUI
import UIKit

/// Everything the reader needs once a comic is open.
final class ReaderSession: ObservableObject {
    let model: ReaderModel
    let companion: CompanionModel
    init(model: ReaderModel, companion: CompanionModel) {
        self.model = model
        self.companion = companion
    }
}

/// Opens the comic file (showing a spinner), then shows the reader.
struct ReaderHost: View {
    let entry: ComicEntry
    @EnvironmentObject var library: LibraryStore
    @EnvironmentObject var settings: AppSettings
    @Environment(\.dismiss) private var dismiss
    @State private var session: ReaderSession?
    @State private var failure: String?

    var body: some View {
        ZStack {
            Color.black.ignoresSafeArea()
            if let s = session {
                ReaderView(entry: entry, model: s.model, companion: s.companion)
            } else if let message = failure {
                VStack(spacing: 16) {
                    Image(systemName: "exclamationmark.triangle.fill")
                        .font(.system(size: 44))
                        .foregroundStyle(Theme.accent)
                    Text(message)
                        .multilineTextAlignment(.center)
                        .foregroundStyle(.white)
                        .padding(.horizontal, 32)
                    Button("Close") { dismiss() }
                        .buttonStyle(YellowButtonStyle())
                }
            } else {
                VStack(spacing: 14) {
                    ProgressView()
                        .tint(.white)
                        .scaleEffect(1.3)
                    Text("Opening…")
                        .font(.footnote)
                        .foregroundStyle(.white.opacity(0.7))
                }
            }
        }
        .task {
            await open()
        }
    }

    private func open() async {
        let url = library.fileURL(for: entry)
        let name = entry.originalName
        let result = await Task.detached(priority: .userInitiated) { () -> Result<(ComicSource, ComicIdentity), Error> in
            do {
                let source = try ComicOpener.open(url: url)
                let identity = IdentityBuilder.make(originalName: name, source: source)
                return .success((source, identity))
            } catch {
                return .failure(error)
            }
        }.value
        switch result {
        case .success(let pair):
            let model = ReaderModel(
                entry: entry,
                source: pair.0,
                identity: pair.1,
                snap: settings.snapToPanels,
                pageFirst: settings.showFullPageFirst
            )
            let companion = CompanionModel(entry: entry, identity: pair.1, settings: settings, coverURL: library.coverURL(for: entry))
            session = ReaderSession(model: model, companion: companion)
        case .failure(let error):
            failure = error.localizedDescription
        }
    }
}

struct ReaderView: View {
    let entry: ComicEntry
    @ObservedObject var model: ReaderModel
    @ObservedObject var companion: CompanionModel

    @EnvironmentObject var library: LibraryStore
    @EnvironmentObject var settings: AppSettings
    @Environment(\.dismiss) private var dismiss

    @State private var chromeVisible = true
    @State private var showCompanion = false
    // Manual zoom (pinch or double-tap). 1 = off, so everything behaves exactly as before until you zoom.
    @State private var zoom = ZoomState()          // not observed here: zooming redraws the page only
    @State private var lastTap: (time: Date, point: CGPoint)?
    @State private var pendingTap: Task<Void, Never>?
    @State private var scrub: Double = 0
    @State private var scrubbing = false
    @Environment(\.scenePhase) private var scenePhase

    /// Puts the slider back on the page that is really showing (after returning to the app, or an interrupted drag).
    private func syncSlider() {
        scrubbing = false
        scrub = Double(model.pageIndex)
    }
    @State private var hideTask: Task<Void, Never>?
    @State private var started = false

    private let haptic = UIImpactFeedbackGenerator(style: .light)

    var body: some View {
        GeometryReader { geo in
            let wide = geo.size.width >= 640
            HStack(spacing: 0) {
                stage(size: stageSize(geo.size, wide: wide))
                if wide && showCompanion {
                    Divider()
                    CompanionView(model: companion, onClose: { toggleCompanion() })
                        .frame(width: min(420, geo.size.width * 0.4))
                        .background(Theme.bg)
                        .transition(.move(edge: .trailing))
                }
            }
            .background(Color.black)
            .sheet(isPresented: Binding(
                get: { showCompanion && !wide },
                set: { newValue in if !newValue { showCompanion = false } }
            )) {
                CompanionView(model: companion, onClose: { showCompanion = false })
                    .presentationDetents([.medium, .large])
                    .presentationDragIndicator(.visible)
                    .presentationBackgroundInteraction(.enabled(upThrough: .medium))
            }
        }
        .ignoresSafeArea()
        .statusBarHidden(!chromeVisible)
        .persistentSystemOverlays(chromeVisible ? .automatic : .hidden)
        .onAppear {
            if !started {
                started = true
                model.start()
                companion.load()
            }
            UIApplication.shared.isIdleTimerDisabled = true
            haptic.prepare()
            syncSlider()
            scheduleHide()
        }
        .onDisappear {
            UIApplication.shared.isIdleTimerDisabled = false
            saveProgress()
            model.finish()
        }
        .onChange(of: model.panelIndex) { _, _ in
            haptic.impactOccurred(intensity: 0.5)
            saveProgress()
        }
        .onChange(of: model.pageIndex) { _, newValue in
            if !scrubbing { scrub = Double(newValue) }
            saveProgress()
        }
        .onChange(of: model.pageCount) { _, _ in syncSlider() }
        .onChange(of: chromeVisible) { _, shown in if shown { syncSlider() } }
        .onChange(of: scenePhase) { _, phase in if phase == .active { syncSlider() } }
        .onChange(of: model.pageIndex) { _, _ in resetZoom() }
        .onChange(of: model.panelIndex) { _, _ in if !zoom.converting { resetZoom() } }
        .onChange(of: settings.snapToPanels) { _, _ in
            model.updateSettings(snap: settings.snapToPanels, pageFirst: settings.showFullPageFirst)
        }
        .onChange(of: settings.showFullPageFirst) { _, _ in
            model.updateSettings(snap: settings.snapToPanels, pageFirst: settings.showFullPageFirst)
        }
    }

    private func stageSize(_ total: CGSize, wide: Bool) -> CGSize {
        if wide && showCompanion {
            return CGSize(width: total.width - min(420, total.width * 0.4) - 1, height: total.height)
        }
        return total
    }

    // MARK: Stage

    private func stage(size: CGSize) -> some View {
        ZStack {
            Color.black

            if let img = model.image {
                ZoomedContent(zoom: zoom) {
                    PanelCanvas(
                        image: img,
                        panels: model.panels,
                        panelIndex: model.panelIndex,
                        size: size,
                        fill: 0.96,
                        animated: !zoom.converting
                    )
                    .id(model.pageIndex)
                    .transition(.opacity)
                    .animation(.easeInOut(duration: 0.3), value: model.pageIndex)
                }
            }

            if model.isLoading && model.image == nil {
                ProgressView().tint(.white).scaleEffect(1.3)
            }

            if let err = model.loadError {
                Text(err)
                    .font(.footnote)
                    .foregroundStyle(.white)
                    .padding(12)
                    .background(.ultraThinMaterial, in: RoundedRectangle(cornerRadius: 12, style: .continuous))
            }

            // Gesture layer
            Color.clear
                .contentShape(Rectangle())
                .gesture(
                    SpatialTapGesture().onEnded { value in
                        handleTap(at: value.location, size: size)
                    }
                )
                .simultaneousGesture(
                    DragGesture(minimumDistance: 24)
                        .onEnded { value in
                            // Zoomed in, or just pinched: the drag belongs to the zoom, so it must not turn the page.
                            if zoom.isZoomed || Date().timeIntervalSince(zoom.lastPinch) < 0.45 { return }
                            handleDrag(value.translation)
                        }
                )

            ZoomGestures(zoom: zoom, enabled: !showCompanion && !scrubbing && !model.reachedEnd,
                         panelFocused: model.panelIndex >= 0,
                         onFlick: { handleDrag($0) },
                         onPinchedOut: { model.showOverview() },
                         onLeavePanel: { leavePanel(size: size) },
                         onEdgeSwipe: { swipedLeft in
                             hideChrome()
                             model.turnPage(forward: model.rtl ? !swipedLeft : swipedLeft)
                         })
                .allowsHitTesting(false)

            // Chrome
            VStack(spacing: 0) {
                if chromeVisible { topBar(size: size).transition(.move(edge: .top).combined(with: .opacity)) }
                Spacer()
                if chromeVisible { bottomBar.transition(.move(edge: .bottom).combined(with: .opacity)) }
            }
            .animation(.easeInOut(duration: 0.22), value: chromeVisible)

            if model.reachedEnd {
                endCard
            }
        }
        .frame(width: size.width, height: size.height)
        .clipped()
    }

    // MARK: Gestures

    /// Tap rules:
    ///  - the outer edges step to the previous / next panel (and onto the next page),
    ///  - a tap on a panel inside the middle area jumps straight to that panel,
    ///  - anywhere else in the middle shows or hides the controls.
    private func handleTap(at point: CGPoint, size: CGSize) {
        let width = max(size.width, 1)
        let f = point.x / width
        let edge: CGFloat = model.panelIndex < 0 ? 0.095 : 0.17    // whole page: slim edges so panels near them stay tappable
        // The edges stay instant. Only the middle waits a moment, to see whether a second tap is coming.
        if f < edge {
            if model.rtl { forward() } else { back() }
            return
        }
        if f > 1 - edge {
            if model.rtl { back() } else { forward() }
            return
        }
        if let last = lastTap, Date().timeIntervalSince(last.time) < 0.3,
           hypot(point.x - last.point.x, point.y - last.point.y) < 60 {
            pendingTap?.cancel()
            lastTap = nil
            doubleTap(at: point, size: size)
            return
        }
        lastTap = (Date(), point)
        pendingTap?.cancel()
        pendingTap = Task {
            try? await Task.sleep(nanoseconds: 300_000_000)
            if Task.isCancelled { return }
            lastTap = nil
            middleTap(at: point, size: size)
        }
    }

    private func middleTap(at point: CGPoint, size: CGSize) {
        if let img = model.image {
            // Undo any zoom or nudge the reader has applied, so the tap lands on the panel that is really under the finger.
            let z = max(zoom.zoom, 0.01)
            let base = CGPoint(x: size.width / 2 + (point.x - size.width / 2 - zoom.offset.width) / z,
                               y: size.height / 2 + (point.y - size.height / 2 - zoom.offset.height) / z)
            if let hit = PanelCanvas.panel(at: base, image: img, panels: model.panels,
                                           panelIndex: model.panelIndex, size: size, fill: 0.96) {
                hideChrome()
                if hit != model.panelIndex {
                    resetZoomInstantly()
                    model.focus(panel: hit)
                } else if isZoomed {
                    zoom.reset()          // already on this panel but nudged or zoomed: snap it back
                }
                return
            }
        }
        if isZoomed { return }
        chromeVisible.toggle()
        if chromeVisible { scheduleHide() }
    }

    private func resetZoomInstantly() {
        zoom.set(zoom: 1, offset: .zero)
    }

    // MARK: Manual zoom

    private var isZoomed: Bool { return zoom.isZoomed }

    private func resetZoom() { zoom.reset() }

    /// Pinching while a panel is focused: show the whole page, keeping exactly what is on screen, so the page can be explored.
    private func leavePanel(size: CGSize) {
        guard model.panelIndex >= 0, let img = model.image else { return }
        let cam = PanelCanvas.camera(image: img, panels: model.panels, panelIndex: model.panelIndex, size: size, fill: 0.96)
        let z = zoom.zoom
        let newZoom = z * cam.zoom
        let newOffset = CGSize(width: z * cam.dx + zoom.offset.width, height: z * cam.dy + zoom.offset.height)
        zoom.converting = true
        var t = Transaction()
        t.disablesAnimations = true
        withTransaction(t) {
            model.showOverview()
            zoom.set(zoom: newZoom, offset: newOffset)    // no clamp: the screen must look exactly as it did
        }
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.3) { zoom.converting = false }
    }

    /// Double-tap: zoom in on the spot you tapped, or zoom back out.
    private func doubleTap(at point: CGPoint, size: CGSize) {
        if isZoomed { resetZoom(); return }
        let z: CGFloat = 2.5
        let c = CGPoint(x: size.width / 2, y: size.height / 2)
        let off = CGSize(width: (point.x - c.x) * (1 - z), height: (point.y - c.y) * (1 - z))
        hideChrome()
        withAnimation(.easeOut(duration: 0.25)) {
            zoom.set(zoom: z, offset: zoom.clamp(off, zoom: z, size: size))
        }
    }

    /// Swipe left/right turns the page, swipe up opens the Companion, swipe down shows the menu (or closes the Companion).
    private func handleDrag(_ t: CGSize) {
        let dx = t.width
        let dy = t.height
        if abs(dx) > 50 && abs(dx) > abs(dy) * 1.3 {
            let swipedLeft = dx < 0
            hideChrome()
            // Swiping left brings the next page (right-to-left comics swipe the other way).
            model.turnPage(forward: model.rtl ? !swipedLeft : swipedLeft)
        } else if dy < -80 && abs(dx) < 70 {
            if !showCompanion { toggleCompanion() }
        } else if dy > 90 && abs(dx) < 70 {
            if showCompanion {
                showCompanion = false
            } else {
                chromeVisible = true          // swipe down = bring up the menu
                scheduleHide()
            }
        }
    }

    private func forward() {
        hideChrome()
        model.goForward()
    }

    private func back() {
        hideChrome()
        model.goBack()
    }

    private func hideChrome() {
        if chromeVisible { chromeVisible = false }
    }

    private func scheduleHide() {
        hideTask?.cancel()
        hideTask = Task {
            try? await Task.sleep(nanoseconds: 5_000_000_000)
            if Task.isCancelled { return }
            chromeVisible = false
        }
    }

    private func toggleCompanion() {
        withAnimation(.easeInOut(duration: 0.25)) {
            showCompanion.toggle()
        }
        if showCompanion { companion.load() }
    }

    private func saveProgress() {
        library.recordProgress(
            id: entry.id,
            page: model.pageIndex,
            panel: model.panelIndex,
            finished: model.reachedEnd
        )
    }

    private func close() {
        saveProgress()
        model.finish()
        dismiss()
    }

    // MARK: Chrome

    private func topBar(size: CGSize) -> some View {
        HStack(spacing: 12) {
            Button(action: { close() }) {
                Image(systemName: "chevron.down")
                    .font(.system(size: 16, weight: .semibold))
                    .frame(width: 40, height: 40)
                    .background(.ultraThinMaterial, in: Circle())
            }
            VStack(alignment: .leading, spacing: 1) {
                Text(entry.title)
                    .font(.subheadline.weight(.semibold))
                    .lineLimit(1)
                Text(positionText)
                    .font(.caption)
                    .foregroundStyle(.white.opacity(0.7))
            }
            Spacer(minLength: 0)
            readerMenu
        }
        .foregroundStyle(.white)
        .padding(.leading, 16)
        .padding(.trailing, Theme.cameraWidth + 30)      // keep the menu button clear of the Duo status widget
        .padding(.top, 54)
        .padding(.bottom, 22)
        .background(
            LinearGradient(colors: [Color.black.opacity(0.65), Color.black.opacity(0)], startPoint: .top, endPoint: .bottom)
        )
    }

    /// Everything you might want while reading, in one place.
    private var readerMenu: some View {
        Menu {
            Toggle(isOn: $settings.snapToPanels) { Label("Snap Panel to Panel", systemImage: "rectangle.split.2x2") }
            Toggle(isOn: $settings.showFullPageFirst) { Label("Whole Page First", systemImage: "doc") }
            Divider()
            if !model.panels.isEmpty {
                Button { model.toggleOverview() } label: {
                    Label(model.panelIndex < 0 ? "Zoom to first panel" : "Show whole page", systemImage: "viewfinder")
                }
            }
            Button { toggleCompanion() } label: { Label("Companion", systemImage: "sparkles") }
            Button { model.reachedEnd = true; close() } label: { Label("Mark as Read and Close", systemImage: "checkmark.circle") }
            Divider()
            Button { close() } label: { Label("Back to Library", systemImage: "chevron.down") }
        } label: {
            Image(systemName: "ellipsis")
                .font(.system(size: 16, weight: .bold))
                .frame(width: 40, height: 40)
                .background(.ultraThinMaterial, in: Circle())
        }
    }

    private var positionText: String {
        var s = "Page \(model.pageIndex + 1) of \(model.pageCount)"
        if model.panelIndex >= 0 && !model.panels.isEmpty {
            s += "  ·  Panel \(model.panelIndex + 1)/\(model.panels.count)"
        }
        return s
    }

    private var bottomBar: some View {
        VStack(spacing: 4) {
            HStack(spacing: 12) {
                Button(action: { model.toggleOverview() }) {
                    Image(systemName: model.panelIndex < 0 ? "viewfinder" : "rectangle.expand.vertical")
                        .font(.system(size: 16, weight: .semibold))
                        .foregroundStyle(.white)

            .foregroundStyle(.white.opacity(0.65))
            .padding(.horizontal, 62)

        .padding(26)
        .background(Theme.card, in: RoundedRectangle(cornerRadius: 26, style: .continuous))
        .padding(40)
    }

===== PanelSnap/Views/ZoomLayer.swift =====
import SwiftUI
import UIKit

/// The reader's manual zoom (pinch and double-tap). It lives in its own object so that zooming only redraws the page,
/// not the whole reader, which is what keeps it smooth.
final class ZoomState: ObservableObject {
    private(set) var zoom: CGFloat = 1
    private(set) var offset: CGSize = .zero
    var lastPinch = Date.distantPast
    var converting = false          // true while switching from a focused panel to the whole page, so the zoom is not reset

    var isZoomed: Bool { return zoom > 1.02 }

    /// Changes zoom and offset together, so the page is redrawn once per frame instead of twice.
    func set(zoom z: CGFloat, offset o: CGSize) {
        objectWillChange.send()
        zoom = z
        offset = o
    }

    func set(offset o: CGSize) { set(zoom: zoom, offset: o) }

    func reset() {
        withAnimation(.easeOut(duration: 0.22)) { set(zoom: 1, offset: .zero) }
    }

    /// How far the page may be moved either way before its edge shows.
    func limits(zoom z: CGFloat, size: CGSize) -> CGSize {
        return CGSize(width: max(z - 1, 0) * size.width / 2, height: max(z - 1, 0) * size.height / 2)
    }

    /// Keeps a zoomed page from being dragged completely out of view.
    func clamp(_ o: CGSize, zoom z: CGFloat, size: CGSize) -> CGSize {
        let m = limits(zoom: z, size: size)
        return CGSize(width: min(max(o.width, -m.width), m.width), height: min(max(o.height, -m.height), m.height))
    }
}

/// Applies the zoom to the page.
struct ZoomedContent<Content: View>: View {
    @ObservedObject var zoom: ZoomState
    @ViewBuilder var content: () -> Content

    var body: some View {
        content()
            .scaleEffect(zoom.zoom)
            .offset(zoom.offset)
    }
}

/// Pinch-to-zoom around the point between your two fingers, with the page following your fingers as they move,
/// plus one-finger dragging while zoomed in (with a little glide when you let go). The recognisers sit on the window,
/// so the reader's own taps and swipes keep working exactly as they did.
struct ZoomGestures: UIViewRepresentable {
    let zoom: ZoomState
    var enabled: Bool
    var panelFocused: Bool                 // on a snapped panel: one finger nudges it, a quick flick still swipes
    var onFlick: (CGSize) -> Void          // a quick flick on a snapped panel: the same as a swipe
    var onPinchedOut: () -> Void           // pinching in on a page that is not zoomed: show the whole page
    var onLeavePanel: () -> Void           // pinching on a focused panel: switch to free zooming on the whole page
    var onEdgeSwipe: (Bool) -> Void        // zoomed in and pushed past the side of the page: true = swiped left

    func makeCoordinator() -> Coordinator { Coordinator(zoom: zoom) }

    func makeUIView(context: Context) -> HookView {
        let v = HookView()
        v.isUserInteractionEnabled = false
        v.coordinator = context.coordinator
        return v
    }

    func updateUIView(_ uiView: HookView, context: Context) {
        context.coordinator.enabled = enabled
        context.coordinator.panelFocused = panelFocused
        context.coordinator.onFlick = onFlick
        context.coordinator.onPinchedOut = onPinchedOut
        context.coordinator.onLeavePanel = onLeavePanel
        context.coordinator.onEdgeSwipe = onEdgeSwipe
    }

    final class HookView: UIView {
        weak var coordinator: Coordinator?
        override func didMoveToWindow() {
            super.didMoveToWindow()
            if let window = window { coordinator?.attach(to: window, stage: self) } else { coordinator?.detach() }
        }
    }

    final class Coordinator: NSObject, UIGestureRecognizerDelegate {
        let zoom: ZoomState
        var enabled = true
        var panelFocused = false
        var onFlick: (CGSize) -> Void = { _ in }
        var onPinchedOut: () -> Void = {}
        var onLeavePanel: () -> Void = {}
        var onEdgeSwipe: (Bool) -> Void = { _ in }
        private var startedAtLeftEdge = false, startedAtRightEdge = false
        private var left = false
        private var baseScale: CGFloat = 1       // the recogniser's scale when the current two-finger hold began
        private var touches = 2
        private weak var stage: UIView?
        private weak var window: UIWindow?
        private lazy var pinch = UIPinchGestureRecognizer(target: self, action: #selector(pinched(_:)))
        private lazy var pan = UIPanGestureRecognizer(target: self, action: #selector(panned(_:)))
        private var start: (zoom: CGFloat, offset: CGSize, point: CGPoint)?
        private var panBase: CGSize = .zero
        private var panTouches = 1               // fingers on the pan last frame; a change means the drag must start afresh
        private var pinchSeen = false            // a pinch ran during this drag, so it is not a swipe
        private var link: CADisplayLink?
        private var glideV = CGPoint.zero        // points per second
        private var glideStamp: CFTimeInterval = 0
        private var glideSize = CGSize.zero

        init(zoom: ZoomState) { self.zoom = zoom }

        func attach(to window: UIWindow, stage: UIView) {
            detach()
            self.window = window
            self.stage = stage
            pan.maximumNumberOfTouches = 2
            for r in [pinch, pan] as [UIGestureRecognizer] {
                r.delegate = self
                r.cancelsTouchesInView = false
                r.delaysTouchesBegan = false
                r.delaysTouchesEnded = false
                window.addGestureRecognizer(r)
            }
        }

        func detach() {
            stopGlide()
            window?.removeGestureRecognizer(pinch)
            window?.removeGestureRecognizer(pan)
            window = nil
        }

        // MARK: Delegate

        func gestureRecognizerShouldBegin(_ g: UIGestureRecognizer) -> Bool {
            guard enabled, let stage = stage, stage.window != nil else { return false }
            if !stage.bounds.contains(g.location(in: stage)) { return false }
            if g === pan { return zoom.isZoomed || panelFocused }   // one finger moves the page when zoomed in, or nudges a snapped panel
            return true
        }

        func gestureRecognizer(_ g: UIGestureRecognizer, shouldRecognizeSimultaneouslyWith other: UIGestureRecognizer) -> Bool {
            return true
        }

        func gestureRecognizer(_ g: UIGestureRecognizer, shouldReceive touch: UITouch) -> Bool {
            if touch.phase == .began { stopGlide() }    // putting a finger down catches a gliding page where it is
            return !(touch.view is UIControl)           // leave sliders and buttons alone
        }

        // MARK: Pinch

        @objc private func pinched(_ g: UIPinchGestureRecognizer) {
            guard let stage = stage else { return }
            let size = stage.bounds.size
            let c = CGPoint(x: size.width / 2, y: size.height / 2)
            switch g.state {
            case .began:
                stopGlide()
                left = false
                baseScale = 1
                touches = g.numberOfTouches
                start = (zoom.zoom, zoom.offset, g.location(in: stage))
                zoom.lastPinch = Date()
            case .changed:
                guard var s = start else { return }
                // With fewer than two fingers down, iOS reports the position of the one left, which would yank the page
                // toward it. Ignore those frames, and start afresh from the current state when the second finger returns.
                if g.numberOfTouches < 2 { touches = g.numberOfTouches; return }
                if touches != g.numberOfTouches {
                    touches = g.numberOfTouches
                    s = (zoom.zoom, zoom.offset, g.location(in: stage))
                    start = s
                    baseScale = g.scale
                    return
                }
                if !left && abs(g.scale / baseScale - 1) > 0.015 {
                    // Pinching on a focused panel: go to the whole page at the same apparent zoom, so you can roam it freely.
                    left = true
                    onLeavePanel()
                    s = (zoom.zoom, zoom.offset, s.point)
                    start = s
                }
                // The spot of the page that was between your fingers when you started stays between them,
                // wherever they move, so the page zooms and follows you at the same time.
                let z = min(max(s.zoom * g.scale / baseScale, 0.8), 12)
                let now = g.location(in: stage)
                let ratio = z / s.zoom
                let off = CGSize(width: (now.x - c.x) - ratio * (s.point.x - c.x - s.offset.width),
                                 height: (now.y - c.y) - ratio * (s.point.y - c.y - s.offset.height))
                // Not clamped while the fingers are down (a panel taken off its snap can sit past the page edge, and pulling it
                // back would make the page jump); it settles inside the limits when the fingers lift.
                zoom.set(zoom: z, offset: off)
                zoom.lastPinch = Date()
            case .ended, .cancelled, .failed:
                guard let s = start else { return }
                start = nil
                zoom.lastPinch = Date()
                if zoom.zoom < 1.05 || (left && g.scale < 0.7) {
                    let showWholePage = s.zoom <= 1.02 && g.scale < 0.85
                    zoom.reset()
                    if showWholePage { onPinchedOut() }
                } else {
                    withAnimation(.easeOut(duration: 0.2)) {
                        zoom.set(offset: zoom.clamp(zoom.offset, zoom: zoom.zoom, size: size))
                    }
                }
            default:
                break
            }
        }

        // MARK: Gliding (momentum after a drag, and the spring back from an edge)

        private func stopGlide() {
            link?.invalidate()
            link = nil
        }

        private func startGlide(velocity: CGPoint, size: CGSize) {
            stopGlide()
            glideV = velocity
            glideSize = size
            glideStamp = 0
            let l = CADisplayLink(target: self, selector: #selector(glideStep(_:)))
            l.add(to: .main, forMode: .common)
            link = l
        }

        /// One frame of momentum. It moves the real offset (not a pending animation), so a touch can catch it exactly,
        /// and a page dragged past its edge eases back while the rest of the movement carries on.
        @objc private func glideStep(_ l: CADisplayLink) {
            guard zoom.isZoomed else { stopGlide(); return }
            let dt = glideStamp == 0 ? l.duration : min(l.timestamp - glideStamp, 1.0 / 20)
            glideStamp = l.timestamp
            let m = zoom.limits(zoom: zoom.zoom, size: glideSize)
            let x = Coordinator.advance(zoom.offset.width, limit: m.width, v: &glideV.x, dt: dt)
            let y = Coordinator.advance(zoom.offset.height, limit: m.height, v: &glideV.y, dt: dt)
            zoom.set(offset: CGSize(width: x.pos, height: y.pos))
            if !x.moving && !y.moving { stopGlide() }
        }

        private static func advance(_ p: CGFloat, limit: CGFloat, v: inout CGFloat, dt: Double) -> (pos: CGFloat, moving: Bool) {
            if p < -limit || p > limit {                       // past the edge: ease back to it
                let target = p < 0 ? -limit : limit
                v = 0
                let np = p + (target - p) * CGFloat(1 - exp(-dt * 16))
                return abs(target - np) < 0.5 ? (target, false) : (np, true)
            }
            v *= CGFloat(pow(0.998, dt * 1000))                 // the same deceleration as a scroll view
            var np = p + v * CGFloat(dt)
            if np < -limit || np > limit {                      // reached the edge: stop there
                np = min(max(np, -limit), limit)
                v = 0
            }
            return (np, abs(v) > 20)
        }

        // MARK: Pan (zoomed in)

        @objc private func panned(_ g: UIPanGestureRecognizer) {
            guard let stage = stage else { return }
            if pinch.state == .began || pinch.state == .changed { pinchSeen = true; return }
            let size = stage.bounds.size
            if !zoom.isZoomed && !converted {
                nudge(g, size: size)
                return
            }
            switch g.state {
            case .began:
                rebase(g, size: size)
            case .changed:
                // After a pinch, or when a finger is added or lifted, carry on from where the page is now
                // rather than from where the drag first began (which would make the page jump).
                if pinchSeen || g.numberOfTouches != panTouches { rebase(g, size: size); return }
                let t = g.translation(in: stage)
                let raw = CGSize(width: panBase.width + t.x, height: panBase.height + t.y)
                let held = zoom.clamp(raw, zoom: zoom.zoom, size: size)
                // Past the edge the page stretches a little and resists, so you can feel that the edge was reached.
                zoom.set(offset: CGSize(width: held.width + (raw.width - held.width) * 0.3,
                                        height: held.height + (raw.height - held.height) * 0.3))
            case .ended:
                converted = false
                let v = g.velocity(in: stage)
                let t = g.translation(in: stage)
                let raw = CGSize(width: panBase.width + t.x, height: panBase.height + t.y)
                let held = zoom.clamp(raw, zoom: zoom.zoom, size: size)
                let pushed = raw.width - held.width          // > 0: dragged right past the left edge; < 0: past the right edge
                let horizontal = abs(t.x) > abs(t.y) * 1.3
                let toNext = startedAtRightEdge && pushed < -40 || startedAtRightEdge && pushed < -8 && v.x < -700
                let toPrevious = startedAtLeftEdge && pushed > 40 || startedAtLeftEdge && pushed > 8 && v.x > 700
                if !pinchSeen && horizontal && (toNext || toPrevious) {
                    withAnimation(.easeOut(duration: 0.2)) { zoom.set(offset: held) }
                    onEdgeSwipe(toNext)
                } else {
                    startGlide(velocity: v, size: size)
                }
            case .cancelled:
                converted = false
                startGlide(velocity: .zero, size: size)
            default:
                break
            }
        }

        /// Starts (or restarts) a drag from the page's current position.
        private func rebase(_ g: UIPanGestureRecognizer, size: CGSize) {
            stopGlide()
            pinchSeen = false
            panTouches = g.numberOfTouches
            g.setTranslation(.zero, in: stage)
            // If the page is resting past its edge (a snapped panel that was just released), start the drag from the
            // point whose stretched position equals where the page is now, so nothing jumps when the finger moves.
            let h = zoom.clamp(zoom.offset, zoom: zoom.zoom, size: size)
            panBase = CGSize(width: h.width + (zoom.offset.width - h.width) / 0.3,
                             height: h.height + (zoom.offset.height - h.height) / 0.3)
            // Only a drag that starts against a side of the page can carry on into a swipe to the next one.
            let maxX = zoom.limits(zoom: zoom.zoom, size: size).width
            startedAtLeftEdge = zoom.offset.width >= maxX - 2
            startedAtRightEdge = zoom.offset.width <= -maxX + 2
        }

        // MARK: Nudging a snapped panel

        private var nudgeBase: CGSize = .zero
        private var converted = false     // this drag has turned into free panning of the whole page

        /// On a snapped panel a quick flick is a swipe. A slower drag lets go of the panel and moves around the
        /// whole page, at the same zoom, so you can look anywhere (the same hand-over a pinch makes).
        private func nudge(_ g: UIPanGestureRecognizer, size: CGSize) {
            switch g.state {
            case .began:
                converted = false
                pinchSeen = false
                g.setTranslation(.zero, in: stage)
            case .changed:
                let t = g.translation(in: stage), v = g.velocity(in: stage)
                zoom.lastPinch = Date()             // keeps the reader's own swipe from also firing
                if hypot(t.x, t.y) > 6 && hypot(v.x, v.y) < 450 {
                    converted = true
                    onLeavePanel()
                    rebase(g, size: size)
                }
            case .ended:
                let v = g.velocity(in: stage), t = g.translation(in: stage)
                zoom.lastPinch = Date()
                let ax = abs(v.x), ay = abs(v.y)
                if !pinchSeen && max(ax, ay) > 700 && max(ax, ay) > 1.3 * min(ax, ay) {
                    onFlick(CGSize(width: t.x, height: t.y))
                }
            default:
                break
            }
        }
    }
}

===== PanelSnap/Views/PanelCanvas.swift =====
import SwiftUI
import UIKit

/// Shows one comic page and smoothly "flies" the camera to the current panel.
struct PanelCanvas: View {
    let image: UIImage
    let panels: [CGRect]
    let panelIndex: Int
    let size: CGSize
    let fill: Double
    var animated = true          // false while a pinch hands a focused panel over to free zooming

    struct Camera {
        var zoom: CGFloat
        var dx: CGFloat
        var dy: CGFloat
        var width: CGFloat
        var height: CGFloat
    }

    static func camera(image: UIImage, panels: [CGRect], panelIndex: Int, size: CGSize, fill: Double) -> Camera {
        let iw = max(image.size.width, 1)
        let ih = max(image.size.height, 1)
        let fit = min(size.width / iw, size.height / ih)
        let dw = iw * fit
        let dh = ih * fit
        var zoom: CGFloat = 1
        var dx: CGFloat = 0
        var dy: CGFloat = 0
        if panelIndex >= 0 && panelIndex < panels.count {
            let p = panels[panelIndex]
            let pw = max(p.width * dw, 1)
            let ph = max(p.height * dh, 1)
            let wanted = min(size.width / pw, size.height / ph) * CGFloat(fill)
            zoom = min(max(wanted, 1), 7)
            dx = -(p.midX - 0.5) * dw * zoom
            dy = -(p.midY - 0.5) * dh * zoom
        }
        return Camera(zoom: zoom, dx: dx, dy: dy, width: dw, height: dh)
    }

    /// Which panel is under a tap? Converts the screen point to page coordinates (0...1) and hit-tests the panels.
    static func panel(at point: CGPoint, image: UIImage, panels: [CGRect], panelIndex: Int, size: CGSize, fill: Double) -> Int? {
        if panels.isEmpty { return nil }
        let cam = camera(image: image, panels: panels, panelIndex: panelIndex, size: size, fill: fill)
        let vx = (point.x - size.width / 2 - cam.dx) / cam.zoom
        let vy = (point.y - size.height / 2 - cam.dy) / cam.zoom
        let nx = 0.5 + vx / max(cam.width, 1)
        let ny = 0.5 + vy / max(cam.height, 1)
        let p = CGPoint(x: nx, y: ny)
        var best: Int?
        var bestArea = CGFloat.greatestFiniteMagnitude
        for (i, r) in panels.enumerated() where r.insetBy(dx: -0.01, dy: -0.01).contains(p) {
            let area = r.width * r.height
            if area < bestArea {
                bestArea = area
                best = i
            }
        }
        return best
    }

    private func camera() -> Camera {
        return PanelCanvas.camera(image: image, panels: panels, panelIndex: panelIndex, size: size, fill: fill)
    }

    var body: some View {
        let cam = camera()
        return Image(uiImage: image)
            .resizable()
            .interpolation(.high)
            .frame(width: cam.width, height: cam.height)
            .scaleEffect(cam.zoom)
            .offset(x: cam.dx, y: cam.dy)
            .animation(animated ? .spring(response: 0.46, dampingFraction: 0.9) : nil, value: panelIndex)
            .frame(width: size.width, height: size.height)
            .clipped()
    }
}

===== PanelSnap/Services/ReaderModel.swift =====
import Foundation
import SwiftUI
import UIKit

/// Drives the reader: loads pages, finds panels and decides where the "camera" points.
@MainActor
final class ReaderModel: ObservableObject {

    enum Target {
        case first
        case last
        case overview
        case index(Int)
    }

    @Published private(set) var pageIndex: Int = 0
    @Published private(set) var panelIndex: Int = 0          // -1 = whole page
    @Published private(set) var image: UIImage?
    @Published private(set) var panels: [CGRect] = []
    @Published private(set) var isLoading = true
    @Published private(set) var loadError: String?
    @Published var reachedEnd = false

    let entry: ComicEntry
    let rtl: Bool
    let pageCount: Int
    private(set) var identity: ComicIdentity

    private let source: ComicSource
    private let panelCache: PanelCache
    private var loadToken = 0
    private var imageCache: [Int: UIImage] = [:]
    private var panelMemo: [Int: [CGRect]] = [:]
    private var prefetching = Set<Int>()        // pages already being prepared in the background
    private var snap: Bool
    private var pageFirst: Bool
    private var observers: [NSObjectProtocol] = []

    init(entry: ComicEntry, source: ComicSource, identity: ComicIdentity, snap: Bool, pageFirst: Bool) {
        self.entry = entry
        self.source = source
        self.identity = identity
        self.pageCount = source.pageCount
        self.rtl = entry.isManga || identity.rtl
        self.panelCache = PanelCache(comicID: entry.id, rtl: entry.isManga || identity.rtl)
        self.snap = snap
        self.pageFirst = pageFirst

        var startPage = entry.lastPage
        var startPanel = entry.lastPanel
        if entry.finished || startPage >= source.pageCount {
            startPage = 0
            startPanel = 0
        }
        self.pageIndex = max(0, min(startPage, source.pageCount - 1))
        self.panelIndex = startPanel

        // Save detected panels if iOS is about to close the app, and shed memory when it asks us to.
        let cache = panelCache
        observers.append(NotificationCenter.default.addObserver(forName: UIApplication.willResignActiveNotification, object: nil, queue: .main) { _ in
            cache.flush()
        })
        observers.append(NotificationCenter.default.addObserver(forName: UIApplication.didReceiveMemoryWarningNotification, object: nil, queue: .main) { [weak self] _ in
            Task { @MainActor in self?.dropFarPages(keeping: self?.pageIndex ?? 0, window: 0) }
        })
    }

    deinit {
        for o in observers { NotificationCenter.default.removeObserver(o) }
    }

    /// Forget decoded pages that are more than `window` pages away from `page`.
    private func dropFarPages(keeping page: Int, window: Int) {
        for key in Array(imageCache.keys) where abs(key - page) > window {
            imageCache.removeValue(forKey: key)
            panelMemo.removeValue(forKey: key)
        }
    }

    func updateSettings(snap: Bool, pageFirst: Bool) {
        let turnedOn = snap && !self.snap
        self.snap = snap
        self.pageFirst = pageFirst
        if !snap { panelIndex = -1 }
        if turnedOn {
            // Pages read in regular mode were never scanned: forget them so they get scanned now.
            panelMemo.removeAll()
            load(page: pageIndex, target: .overview)
        }
    }

    // MARK: Loading

    func start() {
        // A comic you have never opened starts on the whole first page; otherwise resume where you stopped.
        load(page: pageIndex, target: entry.hasStarted ? .index(panelIndex) : .first)
    }

    func finish() {
        panelCache.flush()
    }

    private func load(page: Int, target: Target) {
        loadToken += 1
        let token = loadToken
        let maxPixel: CGFloat = 2600
        let src = source
        let cache = panelCache
        let isRTL = rtl
        let scan = snap            // regular viewer mode never scans for panels

        if let cached = imageCache[page], let memo = panelMemo[page] {
            apply(page: page, image: cached, panels: memo, target: target)
            prefetch(around: page)
            return
        }
        isLoading = true
        loadError = nil

        Task.detached(priority: .userInitiated) { [weak self] in
            guard let cg = src.pageImage(at: page, maxPixel: maxPixel) else {
                await MainActor.run {
                    guard let self = self, token == self.loadToken else { return }
                    self.isLoading = false
                    self.loadError = "Page \(page + 1) couldn't be read."
                }
                return
            }
            var found = cache.panels(for: page)
            if found == nil && scan {
                if let detected = PanelDetector.detect(image: cg, rtl: isRTL) {
                    cache.store(detected, for: page)
                    found = detected
                }
            }
            let rects = found ?? []
            let ui = UIImage(cgImage: cg)
            await MainActor.run {
                guard let self = self else { return }
                self.imageCache[page] = ui
                self.panelMemo[page] = rects
                if token == self.loadToken {
                    self.apply(page: page, image: ui, panels: rects, target: target)
                    self.prefetch(around: page)
                }
            }
        }
    }

    private func apply(page: Int, image: UIImage, panels: [CGRect], target: Target) {
        // Covers, credits and splash pages have nothing to snap to: show them whole instead of guessing.
        let usable = panels.count >= 2 ? panels : []
        pageIndex = page
        self.image = image
        self.panels = usable
        isLoading = false
        loadError = nil
        if !snap || usable.isEmpty {
            panelIndex = -1
            return
        }
        switch target {
        case .first:
            panelIndex = pageFirst ? -1 : 0
        case .last:
            panelIndex = usable.count - 1
        case .overview:
            panelIndex = -1
        case .index(let i):
            panelIndex = max(-1, min(i, usable.count - 1))
        }
    }

    private func prefetch(around page: Int) {
        // Keep only the current page and its two neighbours in memory (each decoded page is tens of MB).
        dropFarPages(keeping: page, window: 1)
        for next in [page + 1, page - 1] where next >= 0 && next < pageCount {
            if imageCache[next] != nil || prefetching.contains(next) { continue }
            prefetching.insert(next)
            let src = source
            let cache = panelCache
            let isRTL = rtl
            let scan = snap            // regular viewer mode never scans for panels
            Task.detached(priority: .utility) { [weak self] in
                guard let cg = src.pageImage(at: next, maxPixel: 2600) else {
                    await MainActor.run { _ = self?.prefetching.remove(next) }
                    return
                }
                var found = cache.panels(for: next)
                if found == nil, scan, let detected = PanelDetector.detect(image: cg, rtl: isRTL) {
                    cache.store(detected, for: next)
                    found = detected
                }
                let rects = found ?? []
                let ui = UIImage(cgImage: cg)
                await MainActor.run {
                    guard let self = self else { return }
                    self.prefetching.remove(next)
                    if abs(next - self.pageIndex) <= 1 {
                        self.imageCache[next] = ui
                        self.panelMemo[next] = rects
                    }
                }
            }
        }
    }

    // MARK: Navigation

    func goForward() {
        if isLoading { return }
        if panelIndex < 0 {
            if snap && !panels.isEmpty {
                panelIndex = 0
            } else {
                nextPage()
            }
        } else if panelIndex + 1 < panels.count {
            panelIndex += 1
        } else {
            nextPage()
        }
    }

    func goBack() {
        if isLoading { return }
        if panelIndex > 0 {
            panelIndex -= 1
        } else if panelIndex == 0 && pageFirst {
            panelIndex = -1
        } else {
            previousPage()
        }
    }

    /// Swipe: turn the page (like the Kindle / Amazon comics reader). The new page opens whole.
    func turnPage(forward: Bool) {
        if isLoading { return }
        if forward {
            nextPage()
        } else if pageIndex > 0 {
            load(page: pageIndex - 1, target: .first)
        }
    }

    func nextPage() {
        if pageIndex + 1 < pageCount {
            load(page: pageIndex + 1, target: .first)
        } else {
            reachedEnd = true
        }
    }

    func previousPage() {
        if pageIndex > 0 {
            load(page: pageIndex - 1, target: snap ? .last : .overview)
        }
    }

    func jump(toPage page: Int) {
        let p = max(0, min(page, pageCount - 1))
        if p == pageIndex { return }
        load(page: p, target: .first)
    }

    func toggleOverview() {
        if panels.isEmpty { return }
        if panelIndex < 0 {
            panelIndex = 0
        } else {
            panelIndex = -1
        }
    }

    /// Tap on a specific panel: fly straight to it.
    func focus(panel index: Int) {
        if isLoading || index < 0 || index >= panels.count { return }
        panelIndex = index
    }

    func showOverview() {
        if panelIndex >= 0 { panelIndex = -1 }
    }

    func focusPanelNearest(to point: CGPoint) {
        // Used after a pinch-out from the page overview: jump to the panel under the centre.
        if panels.isEmpty { return }
        var best = 0
        var bestDistance = CGFloat.greatestFiniteMagnitude
        for (i, r) in panels.enumerated() {
            let dx = r.midX - point.x
            let dy = r.midY - point.y
            let d = dx * dx + dy * dy
            if d < bestDistance {
                bestDistance = d
                best = i
            }
        }
        panelIndex = best
    }
}

===== PanelSnap/Services/PanelDetector.swift =====
import Foundation
import CoreGraphics

/// Finds the panels on a comic page. Panels are found by a neural network (see `MLPanelDetector`); there is
/// no rule-based backup. A page where nothing is found (a splash page, say) is shown whole.
enum PanelDetector {
    /// Bump when detection changes so panels saved from an older version are found again.
    static let version = 10

    /// Panels in reading order as 0...1 rectangles with a top-left origin. A page with no panels comes back as the
    /// whole page. Nil means the model could not run this time, so the answer should not be saved.
    static func detect(image: CGImage, rtl: Bool) -> [CGRect]? {
        guard let found = MLPanelDetector.detect(image: image, rtl: rtl) else { return nil }
        return found.isEmpty ? [CGRect(x: 0, y: 0, width: 1, height: 1)] : found
    }
}

===== PanelSnap/Services/PanelCache.swift =====
import Foundation
import CoreGraphics

/// Remembers detected panels so a page is only analysed once.
final class PanelCache {
    private struct Stored: Codable {
        var version: Int
        var pages: [String: [[Double]]]
        var rtl: Bool
    }

    private var stored: Stored
    private let url: URL
    private var dirty = false
    private let lock = NSLock()

    static func fileURL(for id: UUID) -> URL {
        return Paths.panelCache.appendingPathComponent(id.uuidString + "-d3.json")
    }

    init(comicID: UUID, rtl: Bool) {
        url = PanelCache.fileURL(for: comicID)
        if let data = try? Data(contentsOf: url),
           let s = try? JSONDecoder().decode(Stored.self, from: data),
           s.version == PanelDetector.version, s.rtl == rtl {
            stored = s
        } else {
            stored = Stored(version: PanelDetector.version, pages: [:], rtl: rtl)
        }
    }

    func panels(for page: Int) -> [CGRect]? {
        lock.lock()
        defer { lock.unlock() }
        guard let raw = stored.pages[String(page)] else { return nil }
        return raw.compactMap { a in
            a.count == 4 ? CGRect(x: a[0], y: a[1], width: a[2], height: a[3]) : nil
        }
    }

    func store(_ rects: [CGRect], for page: Int) {
        lock.lock()
        stored.pages[String(page)] = rects.map { [Double($0.origin.x), Double($0.origin.y), Double($0.size.width), Double($0.size.height)] }
        dirty = true
        lock.unlock()
    }

    func flush() {
        lock.lock()
        defer { lock.unlock() }
        if !dirty { return }
        if let data = try? JSONEncoder().encode(stored) {
            try? data.write(to: url, options: .atomic)
        }
        dirty = false
    }
}
